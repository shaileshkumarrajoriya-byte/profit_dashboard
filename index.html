Install App

Is file ko is tarah Home Screen par add karein:

Android (Chrome): Upar-right corner mein ⋮ (teen dot) menu par tap karein, phir "Add to Home screen" ya "Install app" choose karein.

iPhone (Safari): Neeche Share icon ⬆ par tap karein, phir "Add to Home Screen" choose karein.

Note: File ko computer/download se seedhe khola gaya ho to automatic install prompt nahi aata — upar wala tareeka use karein.
